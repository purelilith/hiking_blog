# Tropa — каталог и блог пеших маршрутов по России

Сайт, где путешественники публикуют маршруты как посты (текст и фото), отмечают на карте линию маршрута и важные места, а также указывают сроки работы, ограничения, источники и паспорт доступности.

## Возможности
- Каталог маршрутов с фильтрами (регион, сложность, тип маршрута, сезон, местность, длина, дни, «без ступенек»), сортировкой и страницами.
- Проверенные маршруты и маршруты от путешественников; метки «закрыт», «вне сезона», «данные могли устареть».
- Свои маршруты: линия на карте, названные места, фото в тексте описания, публичный или приватный маршрут, правка и удаление.
- Паспорт доступности, сроки работы, ограничения, источник и дата проверки данных.
- Чек-лист снаряжения под сезон, местность и длительность.
- Вход по имени и паролю или через Google.
- Светлая и тёмная тема, повышенный контраст, размер шрифта; управление с клавиатуры, работа со скринридерами.

## Технологии
Python 3 и Flask, SQLite, шаблоны Jinja2, карты Leaflet (OpenStreetMap и OpenTopoMap), обычный JavaScript.

## Запуск
Нужен Python 3.10 или новее.

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
flask --app app init-db         # создаёт базу данных (ВНИМАНИЕ: стирает старые данные)
python seed.py                  # заполняет базу снаряжением и примерами маршрутов
flask --app app run --debug
```

Сайт откроется на http://127.0.0.1:5000.

`python seed.py ИМЯ` записывает примеры маршрутов на вашего пользователя, чтобы их можно было править на сайте. `python export_routes.py ИМЯ` выгружает проверенные маршруты этого пользователя обратно в `seed_data.json` и `seed_photos/`.

### Настройки (необязательно, файл `.env`)
| Переменная | Назначение |
|---|---|
| `SECRET_KEY` | ключ подписи сессий; если не задан, создаётся файл `.secret_key` |
| `COOKIE_SECURE=1` | включить на хостинге с HTTPS |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | вход через Google (если не заданы, кнопка скрыта) |
| `FLASK_DEBUG=1` | режим отладки (на хостинге выключить) |

## Хостинг
Точка входа: объект `app` в `app.py`. На хостинге задайте `SECRET_KEY` и `COOKIE_SECURE=1`, выключите отладку. Папка `static/img` должна быть доступна для записи. На некоторых бесплатных тарифах диск временный, и база с загруженными фото может пропадать при перезапуске.

## Структура проекта
```
app.py              создание сайта и подключение разделов
config.py           настройки
db.py               подключение к SQLite, создание и обновление таблиц
extensions.py       защита от CSRF, ограничение частоты запросов, Google-вход
schema.sql          описание таблиц
seed.py             начальные данные (снаряжение, маршруты)
seed_data.json      маршруты для seed.py
seed_photos/        обложки для seed.py
export_routes.py    выгрузка проверенных маршрутов в seed_data.json
views/              auth.py (вход), pages.py (главная, о проекте), routes.py (маршруты)
templates/          страницы (Jinja2)
static/             стили, скрипты, шрифты и изображения
docs/architecture.md  описание архитектуры
```

## Безопасность
Пароли хранятся в виде хешей; запросы к базе параметризованы; формы защищены от подделки (CSRF); ограничено число попыток входа и загрузок; загружаемые файлы проверяются по содержимому; текст пользователей экранируется при выводе; задан набор защитных заголовков.

## Известные ограничения
Нет восстановления пароля; информация о маршрутах вносится авторами и может устареть.
