# Tropa — каталог и блог пеших маршрутов по России

Сайт, где путешественники публикуют маршруты как посты: с текстом и фото, линией пути и важными местами на карте. У каждого маршрута указаны сроки работы, ограничения, источник данных, дата проверки и паспорт доступности.

## Возможности

- **Каталог** с фильтрами (регион, сложность, тип маршрута, сезон, местность, длина, число дней, «без ступенек»), сортировкой и постраничным выводом.
- **Два типа маршрутов:** проверенные и от путешественников. Метки «закрыт», «вне сезона» и «данные могли устареть» подсказывают, насколько информации можно доверять.
- **Свои маршруты:** линия на карте, названные места, фото в тексте описания, публичная или приватная видимость, правка и удаление.
- **Паспорт доступности:** покрытие, уклон, ступеньки, места отдыха.
- **Чек-лист снаряжения** под сезон, местность и длительность маршрута.
- **Вход** по имени и паролю или через Google.
- **Доступность:** светлая и тёмная тема, повышенный контраст, размер шрифта, управление с клавиатуры, поддержка скринридеров.

## Технологии

Python 3 и Flask, SQLite, шаблоны Jinja2, карты Leaflet (OpenStreetMap и OpenTopoMap), обычный JavaScript.

## Быстрый старт

Нужен Python 3.10 или новее.

```bash
git clone https://github.com/purelilith/hiking_blog.git
cd hiking_blog

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

flask --app app init-db         # создаёт пустую базу (стирает старые данные!)
python seed.py                  # добавляет снаряжение и 4 проверенных маршрута
flask --app app run
```

Сайт откроется на http://127.0.0.1:5000.

После этого каталог содержит 4 проверенных маршрута с линиями на карте, названными местами и обложками. Посетитель видит их без входа: маршруты публичные, а войти под их служебным автором нельзя.

> Файл базы `hiking.db` создаётся локально и в репозиторий не попадает. Каждый, кто запускает проект, получает собственную базу.

## Данные для примера

Маршруты хранятся в репозитории в виде файлов, а не в базе:

- `seed_data.json` — параметры, описания, линии и места маршрутов;
- `seed_photos/route1.jpg … route4.jpg` — обложки.

`python seed.py` читает эти файлы и записывает маршруты в базу. Повторный запуск безопасен: маршруты с теми же названиями заменяются, остальные данные не затрагиваются.

| Команда | Что делает |
|---|---|
| `python seed.py` | записывает маршруты на служебного пользователя `catalog` с неизвестным паролем |
| `python seed.py ИМЯ` | записывает маршруты на вашего пользователя, чтобы их можно было править на сайте. Сначала зарегистрируйтесь под этим именем |
| `python export_routes.py ИМЯ` | выгружает проверенные маршруты этого пользователя обратно в `seed_data.json` и `seed_photos/` |

Чтобы изменить маршруты в репозитории: загрузите их на своего пользователя, отредактируйте на сайте, выгрузите командой `export_routes.py` и закоммитьте обновлённые файлы.

## Настройки (необязательно, файл `.env`)

| Переменная | Назначение |
|---|---|
| `SECRET_KEY` | ключ подписи сессий; если не задан, создаётся файл `.secret_key` |
| `COOKIE_SECURE=1` | включить на хостинге с HTTPS |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | вход через Google (если не заданы, кнопка скрыта) |
| `FLASK_DEBUG=1` | режим отладки; на хостинге и в локальной сети выключить |

Файлы `.env` и `.secret_key` в репозиторий не попадают.

## Размещение на хостинге

Точка входа — объект `app` в `app.py`. На хостинге задайте `SECRET_KEY` и `COOKIE_SECURE=1`, выключите отладку. Папка `static/img` должна быть доступна для записи. На некоторых бесплатных тарифах диск временный: база и загруженные фото могут пропадать при перезапуске.

## Структура проекта

```
app.py              создание сайта и подключение разделов
config.py           настройки
db.py               подключение к SQLite, создание и обновление таблиц
extensions.py       защита от CSRF, ограничение частоты запросов, вход через Google
schema.sql          описание таблиц
seed.py             начальные данные: снаряжение и маршруты
seed_data.json      маршруты для seed.py (параметры, линии, места)
seed_photos/        обложки маршрутов для seed.py
export_routes.py    выгрузка проверенных маршрутов в seed_data.json и seed_photos/
views/              auth.py (вход), pages.py (главная, «О проекте»), routes.py (маршруты)
templates/          страницы (Jinja2)
static/             стили, скрипты, шрифты и изображения
docs/architecture.md  описание архитектуры
```

## Безопасность

- Пароли хранятся в виде хешей.
- Запросы к базе параметризованы.
- Формы защищены от подделки запросов (CSRF).
- Число попыток входа, регистраций и загрузок ограничено.
- Загружаемые файлы проверяются по содержимому.
- Текст пользователей экранируется при выводе.
- Заданы защитные заголовки и флаги cookie.

## Известные ограничения

- Нет восстановления пароля.
- Данные о маршрутах вносят авторы, они могут устареть.
- Сайт рассчитан на локальный запуск и небольшую нагрузку: база SQLite, ограничение частоты запросов хранится в памяти.
