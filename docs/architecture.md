# Архитектура Tropa

## Общая схема
```
Браузер ──► Flask (app.py)
              ├─ views/auth.py    вход, регистрация, выход, вход через Google
              ├─ views/pages.py   главная, «О проекте», подгрузка популярных маршрутов
              └─ views/routes.py  каталог, страница маршрута, форма, фото, правка
                      │
                      ├─► db.py ──► SQLite (hiking.db)
                      └─► templates/ (Jinja2) ──► HTML ──► static/ (CSS, JS, изображения)
```
Приложение собирается функцией `create_app()`: загружает настройки, подключает защиту (CSRF, ограничение частоты запросов), вход через Google и три раздела (blueprint).

## Как обрабатывается запрос
Пример: открытие страницы маршрута `/routes/5`. Flask находит функцию `detail`, она читает маршрут, его точки, места, фото и подходящее снаряжение из базы, передаёт данные в шаблон `route_detail.html` и возвращает готовую страницу. Тексты авторов при выводе экранируются, фото в описании подставляются на место меток `[фото:N]`.

## База данных
| Таблица | Назначение |
|---|---|
| `users` | пользователи (пароль в виде хеша, поля для Google-входа) |
| `routes` | маршруты: параметры, описание, сроки, ограничения, источник, паспорт доступности, видимость, просмотры, тип (`curated` или `community`), признак `is_closed` |
| `route_points` | линия маршрута (`kind='path'`) и названные места (`kind='place'`, с названием и заметкой) |
| `route_photos` | фото внутри описания с обязательным текстовым описанием |
| `gear_items` | снаряжение с метками сезона, местности и минимального числа дней |

Связи: пользователь → много маршрутов; маршрут → много точек и фото (при удалении маршрута удаляются сами). Индексы построены по полям фильтров каталога (регион, сложность, длина) и по `route_id`. При запуске `db.ensure_schema()` добавляет недостающие столбцы и таблицы в старую базу, не трогая данные.

## Ключевые решения
- **SQLite:** файл без отдельного сервера, достаточно для проекта и просто запускается.
- **Линия и места отдельно:** линию можно строить по каждому повороту, а названные места показывать читателю в списке и на карте.
- **Фото в тексте:** метки `[фото:N]`; при сохранении маршрута сервер привязывает фото к нему, а лишние удаляет.
- **Приватные маршруты:** фильтр `is_public` применяется в каждом запросе, чужой приватный маршрут открывается как «не найден».
- **Метки маршрута:** `route_badges()` по типу маршрута, закрытию, срокам и дате проверки данных выдаёт метки для карточек и страницы маршрута.

## Безопасность
Параметризованные запросы; хеши паролей; CSRF-токены во всех POST-формах и в запросах загрузки фото; ограничение частоты запросов на вход, регистрацию и загрузку; проверка типа файла по сигнатуре и случайные имена файлов; экранирование пользовательского текста; защитные заголовки и флаги cookie.

## Доступность
Цвета заданы переменными CSS и меняются по атрибутам `data-theme` и `data-contrast` на `<html>`; размер шрифта задаётся процентом корневого шрифта, а все размеры в `rem`. Настройки сохраняются в браузере (`static/js/a11y.js`). Карта дублируется текстовым списком мест и координат.
